# C Programming – Class Work and In-Lab Tasks

## Course Overview
This course introduces the basics of C programming and develops fundamental programming and problem-solving skills.

## Topics Covered in Class
- Basics of C Programming
- Structure of a C Program
- Execution of a C Program
- Variables
- Data Types
- Data Type Specifiers
- Input and Output
- If, Else If and Else Conditions
- Solving Programming Questions using Conditional Statements

## Class Work
During the class, we studied the above concepts and practiced writing simple C programs. We also solved different programming questions using variables, data types, specifiers, and if-else conditions.

## In-Lab Tasks
At the end of the class, we completed in-lab programming tasks based on the topics covered in the lecture.

The tasks involved:
- Declaring and using appropriate variables
- Using suitable data types and specifiers
- Taking input from the user
- Applying if-else and else-if conditions
- Solving problem-based questions using C programming

## Post_Lab_Tasks_04
After the class, the teacher assigned Post-Lab Tasks 04 to be completed at home. These tasks were based on the concepts studied in class and were given for additional practice and understanding.

The completed Post-Lab Tasks 04 are included in this repository for submission and evaluation.

## Learning Outcome
After completing the class work, in-lab tasks, and post-lab tasks, I developed a basic understanding of C programming and learned how to use variables, data types, specifiers, and conditional statements to solve programming problems.
